# Sivra Landing Page

Static landing page shell for Cloud Pages hosting.

## Pages

- `index.html`
- `privacy.html`
- `terms.html`
- `faq.html`
- `support.html`

Support uses email only: `support@veloranlabs.com`. There is no support form.

Footer identity: `© 2026 Veloran Labs`.

## Local Preview

From the repo root:

```sh
python3 -m http.server 4173 --directory landing
```

Open `http://localhost:4173`.

## Cloud Pages

Use `landing/` as the publish directory. No build command is required.
